## GetSortTmpSize

### 功能说明

获取Sort接口所需的临时空间大小。

### 函数原型

```cpp
   uint32_t GetSortTmpSize(const platform_ascendc::PlatformAscendC &ascendcPlatform, const uint32_t
elemCount, const uint32_t dataTypeSize)
```

### 参数说明

表4-851 接口参数列表

### 参数名 输入/输 描述

出

ascendcPlat 输入传入硬件平台的信息，PlatformAscendC定义请参见form 4.6.2.1.2 构造及析构函数。

elemCount 输入输入元素个数。

dataTypeSi 输入输入数据大小（单位为字节）。ze

### 返回值说明

Sort接口所需的临时空间大小。

### 约束说明

### 无

### 调用示例

```cpp
    fe::PlatFormInfos platform_info;
auto plat = platform_ascendc::PlatformAscendC(&platform_info);
  const uint32_t elemCount = 128;
  AscendC::GetSortTmpSize(plat, elemCount, 4);
```
