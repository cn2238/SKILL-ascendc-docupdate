## Copy

### 功能说明

VECIN，VECCALC，VECOUT之间的搬运指令，支持mask操作和DataBlock间隔操作。

### 函数原型

- tensor高维切分计算
- mask逐bit模式
```cpp
template <typename T, bool isSetMask = true>
    __aicore__ inline void Copy(const LocalTensor<T>& dst, const LocalTensor<T>& src, const
   uint64_t mask[], const uint8_t repeatTime, const CopyRepeatParams& repeatParams)
```

- mask连续模式
```cpp
template <typename T, bool isSetMask = true>
    __aicore__ inline void Copy(const LocalTensor<T>& dst, const LocalTensor<T>& src, const
   uint64_t mask, const uint8_t repeatTime, const CopyRepeatParams& repeatParams)
```
