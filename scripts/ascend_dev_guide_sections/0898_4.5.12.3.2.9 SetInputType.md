## SetInputType

### 功能说明

设置特征矩阵Input的位置、数据格式、数据类型信息，这些信息必须与Kernel侧的设置保持一致。

### 函数原型

```cpp
   void SetInputType(ConvCommonApi::TPosition pos, ConvCommonApi::ConvFormat format,
ConvCommonApi::ConvDtype dtype)
```

### 参数说明

表4-984 参数说明

### 参数名 输入/输出 描述

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| format | 输入 | Input的数据格式。当前仅支持ConvFormat::NDC1HWC0。 |
| dtype | 输入 | Input的数据类型。当前仅支持ConvDtype::FLOAT16、<br>`ConvDtype::BF16。` |

### 返回值说明

### 无

### 约束说明

### 无

   optiling::Conv3DBackpropFilterTilingData tilingData;
auto ascendcPlatform = platform_ascendc::PlatformAscendCManager::GetInstance();

 conv3dBpDwTiling.SetInputType(ConvCommonApi::TPosition::GM,
