# 3.3.3.3.1 Matmul特性介绍

3.3.3.3.1 Matmul 特性介绍

         除了前述基础知识和算子实现中介绍的基本计算能力外，Matmul矩阵编程还提供了适
        用于不同场景的处理能力及多种功能，具体场景和功能列于下表中，详细内容请见后
        续章节。

            表3-4 Matmul 功能特性表

         特性描述     功能简介

         多核对齐切分   在多核场景中，支持将矩阵数据沿M、N、K轴切分，满足M能
                          被singleCoreM整除、N能被singleCoreN整除、K能被
                     singleCoreK整除的对齐场景时的处理方式，从而实现多核并行
                  计算矩阵乘。

         多核非对齐切分  在多核场景中，支持将矩阵数据沿M、N、K轴切分。当出现M
                         不能被singleCoreM整除、或N不能被singleCoreN整除、或K不
                     能被singleCoreK整除的非对齐场景（即尾块场景）时的处理方
                  式。

         异步场景处理   MIX场景（包含矩阵计算和矢量计算）下不需要等待矩阵乘计算
                  完成，先执行其它计算。

         矩阵乘输出的量  将矩阵乘的计算结果从CO1搬出到Global Memory时，对矩阵
          化/反量化     元素执行数据量化或反量化操作。

         自定义数据搬入  自定义矩阵乘计算前后的数据搬运函数。本功能支持用户实现
         搬出         左矩阵A、右矩阵B从Global Memory分别自定义搬入到A1、B1
                     的过程，输出C矩阵从CO1自定义搬出到Global Memory的过
                  程。

         矩阵乘输出的    矩阵乘输出的Channel拆分，又称ChannelSplit。指float数据类
             Channel拆分   型、NZ数据格式的输出C矩阵按照16*8的分形大小存储。

         矩阵向量乘    矩阵向量乘即GEMV，指矩阵乘计算中M=1，K>1的场景，即对
                         形状为(1, K)的左矩阵A实现矩阵乘计算。

           4:2稀疏矩阵乘   4:2稀疏矩阵乘，又称Sparse Matmul。指对稀疏左矩阵A和4:2
                  稠密化的右矩阵B实现矩阵乘计算。

         上/下三角矩阵乘  忽略位于矩阵中下三角或上三角位置的元素的计算，实现矩阵
                  中上三角或下三角位置的元素的矩阵乘计算。

          TSCM输入的矩阵 对内存逻辑位置为TSCM的左矩阵A或右矩阵B实现矩阵乘计
         乘        算。

特性描述     功能简介

         矩阵乘输出的N方 矩阵乘输出的N方向对齐，又称ND_ALIGN格式输出。指对数据
         向对齐       格式为ND_ALIGN的输出C矩阵实现N方向32字节对齐的自动补
                  齐及输出。

         单次矩阵乘局部  单次矩阵乘局部输出，又称Partial Output，指矩阵乘计算时不
         输出       对单核K方向的计算结果做累加，直接输出计算结果。

            AIC和AIV独立运  AIC和AIV独立运行机制，又称双主模式。MIX场景（包含矩阵
         行机制       计算和矢量计算）下AIC核和AIV核独立运行代码，不依赖消息
                  驱动。
