# 2.7.1 概述

2.7.1 概述
               Ascend C算子调试的整体方案如下：开发者通过调用Ascend C类库编写Ascend C算子
          Kernel侧源码，Kernel侧源码通过通用的GCC编译器进行编译，编译生成通用的CPU域
         的二进制，可以通过gdb通用调试工具等调试手段进行调试；Kernel侧源码通过毕昇编
         译器进行编译，编译生成NPU域的二进制文件，可以通过仿真打点图或者Profiling工
        具进行上板数据采集等方式进行调试。
